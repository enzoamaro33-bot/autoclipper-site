Les meilleurs moments de vos streams,
clippés tout seuls.

AUTOCLIPPER tourne en local sur votre Mac : il surveille un livestream (Twitch aujourd'hui), repère les moments qui sortent du lot, en découpe des clips courts au format vertical avec sous-titres générés automatiquement, et les prépare pour vos réseaux — TikTok et YouTube via leurs API officielles, Instagram en préparation.

Voir comment ça marche Intégration TikTok

Un pipeline entièrement local

Tout se passe sur votre machine : capture, analyse, montage. Rien n'est envoyé où que ce soit tant que vous ne le décidez pas explicitement.

🎥 Capture du live (flux direct) → 🔎 Détection des moments forts → ✂️ Découpe du clip → 📱 Format vertical 1080×1920 → 💬 Sous-titres automatiques → ⭐ Scoring → 📂 Classement par streamer / date
🖥️

100% desktop, 100% local

Aucun serveur distant. La capture, l'analyse et le montage tournent directement sur votre Mac.

🧠

Détection automatique

Repère les pics d'intensité (audio, réactions) pour isoler les passages qui valent le coup d'être coupés.

📱

Prêt pour les réseaux

Format vertical 1080×1920, sous-titres générés automatiquement, durée toujours limitée à 80 secondes maximum.

🗂️

Organisation automatique

Chaque clip est rangé par streamer puis par date, avec un aperçu consultable dans une interface locale dédiée.

Publication : TikTok, YouTube, Instagram

Une fois un clip prêt, vous pouvez l'envoyer vers votre compte TikTok ou YouTube en un clic, via leurs API officielles respectives — toujours sous votre contrôle direct. L'intégration Instagram est préparée dans l'architecture mais pas encore active : l'API Instagram exige un compte Business/Creator validé et un hébergement public des vidéos, ce qui n'est pas encore réuni.

Ce que fait l'intégration :
  • Vous connectez votre propre compte TikTok via la procédure d'autorisation officielle de TikTok (OAuth) — AUTOCLIPPER ne voit jamais votre mot de passe.
  • Vous choisissez le clip, écrivez une description et des hashtags.
  • Le clip est envoyé dans votre boîte de réception TikTok en tant que brouillon.
  • Vous finalisez et publiez vous-même, depuis l'application TikTok, quand vous le souhaitez.
Ce que l'intégration ne fait jamais :
  • Aucune publication publique automatique. Un clip envoyé reste un brouillon tant que vous n'avez pas vous-même appuyé sur "publier" dans TikTok.
  • Aucun scraping ni automatisation de l'interface TikTok. Uniquement l'API officielle "Content Posting API".
  • Aucune donnée TikTok envoyée ailleurs qu'à TikTok lui-même.

AUTOCLIPPER utilise l'API officielle TikTok. Consultez notre Privacy Policy pour le détail des données concernées.
